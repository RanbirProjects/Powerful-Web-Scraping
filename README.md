# MERN Web Scraper Clone

This project is a MERN stack boilerplate inspired by [Bright Data's web scraping platform](https://brightdata.com/lp/web-data/scraping-2?kw=simple%20web%20scraper...).

## Project Structure

```
Web scapper/
├── client/         # React frontend
│   └── ...
├── server/         # Express backend
│   ├── models/
│   ├── routes/
│   ├── controllers/
│   ├── index.js
│   └── .env
└── README.md
```

## Getting Started

### Backend
1. `cd server`
2. `npm install`
3. Create a `.env` file with your MongoDB URI and PORT.
4. `node index.js`

### Frontend
1. `cd client`
2. `npm install`
3. Create a `.env` file with `REACT_APP_API_URL`.
4. `npm start`

---

This is a starter template. You can now build out the frontend and backend to match the features and design of the reference site. # Powerful-Web-Scraping
